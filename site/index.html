Instalar no celular

  1. Toque em "Baixar mod". O arquivo Shadowbound.mcaddon vai para a pasta Downloads.
  2. Abra o arquivo e escolha "Minecraft". O jogo abre e mostra "Importação concluída" duas vezes.
  3. Ative no mundo. Configurações do mundo → Pacotes de comportamento → Shadowbound → Ativar (aceite ativar o visual junto).
  4. Entre e use o Invocador das Sombras. Você ganha o item ao entrar. Segure e use para escolher sua companheira.

Peça do seu jeito

Toque num comando para copiar. Ou toque na sua companheira para abrir o menu.

Se der algum problema

O celular não oferece "Abrir com Minecraft"

Abra pelo app Files by Google. Se o arquivo baixou como .zip, renomeie para Shadowbound.mcaddon e abra de novo.

Usei o download reserva (.zip)

Renomeie o arquivo de Shadowbound.zip para Shadowbound.mcaddon (no app de arquivos: segure o arquivo → Renomear) e toque nele.

O comando /sombra não aparece

Use o nome completo: /shadowbound:sombra pegue madeira. Ou toque na companheira para usar o menu.

Perdi o Invocador das Sombras

Na bancada: livro + graveto + carvão. Ou digite /sombra invocar luna (ou raven, sora, yuki).
