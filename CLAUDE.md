# SHADOWBOUND — Agent Handoff

Minecraft Bedrock add-on (Behavior Pack + Resource Pack + Script API in TypeScript): owner-bound shadow companions
(personas Luna, Raven, Sora, Yuki, Hana and Aiko, plus 12 shadow beasts) organised in per-owner squads, that take Portuguese orders and perform real actions. Everything below is true for this repo;
keep it true when you change things.

## Layout
- `behavior_pack/` — manifest, entities `shadowbound:companion` and `shadowbound:beast` (the beast JSON is GENERATED by `tools/gen_beast_entity.py`), item `shadowbound:shadow_summoner`, recipe, lang. `scripts/main.js` is BUILT (gitignored).
- `resource_pack/` — 2 client entities, 18 geometries (6 humanoids + 12 beasts), textures (humanoids 1024 px: 128 UV units × 4 px × 2 upscale; beasts 512 px: smallest atlas that fits, 64 units × 8 px or 128 × 4), animations, animation controller, render controller, particles, lang. Models/textures/animations are GENERATED.
- `scripts/` — TypeScript source, one folder per brain module (see documentation/ARQUITETURA.md). Squad logic: `ai/squad.ts`; beasts: `core/species.ts` + `combat/beasts.ts`; build materials: `building/materials.ts`.
- `tools/art/generate_art.py` — generates geometry + texture together (UVs can never drift). Humanoid faces: every expression overlay (glow eyes, lids, happy eyes, angry brows) is a CROP of a full `face_render()` so overlays match the head pixel for pixel — keep it that way. Painters flagged `hires` are painted at full resolution; others get `light_pass()` + smooth upscale. Beasts: per-species palette `PALS` + `pelt()` painter; emissive eye bands are crops of the head face (`glow_crop`). `generate_anims.py` — animations, controllers, render controllers, client entities. Beasts have a FULL animation set per species (`S[...]` dict: idle/move/walk/run/attack/cast/guard/summon/secondary) and one controller whose `start` state routes by `shadowbound:species`; the validator checks each species' animations only touch bones of that species' model.
- `tools/build.mjs` (bundle + validate + zip to `dist/`), `tools/validate-packs.mjs` (cross-reference checks), `tools/run-tests.mjs`.
- `tests/` — pure unit tests + `integration.test.ts` running the real brain against `tests/mock/` (a simulator of the API surface we use).
- `dist/` — committed deliverables: `Shadowbound.mcaddon` (+ separate `.mcpack`s). Rebuild after any change.
- `site/template.html` → `site/index.html` (built by tools/build.mjs): the download page; the button links to the `.mcaddon` on GitHub.
- `optional/` — LLM backend + BDS-only bridge pack. The main add-on must never depend on them.

## Rules
- Only STABLE Script API. Declared versions: `@minecraft/server` 2.3.0, `@minecraft/server-ui` 2.1.0, min engine 1.26.40. devDependencies are pinned to the same versions so `npm run typecheck` checks exactly what the manifest declares. Never use `chatSend` (beta).
- Owner checks (`isOwner`, by `player.id`, never by name) at every entry point. Messages go only to the owner.
- Inventory/equipment/task/needs live in the world record (`sb:agent:<ownerId>:<memberId>`, squad index `sb:squad:<ownerId>`), never in the body. Never add `minecraft:inventory` or loot to the entity.
- Task runners are generators that must stay RESTARTABLE from `task.data`/`task.progress` (interrupt/death/reload restart them).
- Never report a task as done without verifying (see `finish()` in executor/tasks.ts).
- `AnimState` (scripts/core/constants.ts) must match `STATES` in tools/art/generate_anims.py — the validator enforces it.
- After editing art: `npm run art`. After any change: `npm run all` (typecheck + 48 tests + build). Commit `dist/`.
- Beasts never gather, craft or build (`BEAST_TASKS`). Species stats in `core/species.ts` must match the generated beast JSON — the validator enforces it.
- User-facing text is Brazilian Portuguese. Keep the companions' designs non-sexualized; do not add sexual content.
