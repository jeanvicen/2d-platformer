# Jujutsu Kaisen: Legado (repo "SHADOWBOUND") — Agent Handoff

Minecraft Bedrock add-on (Behavior Pack + Resource Pack + Script API in TypeScript), v4.0: a personal FAN mod inspired by
Jujutsu Kaisen. On first join a clan roulette assigns a clan + innate technique; the player casts abilities from the
"Grimório Jujutsu" (item id `shadowbound:shadow_summoner`, kept for compatibility). Ten Shadows users summon shikigami
(the `shadowbound:beast` entity driven by the agent brain). The humanoid companions of v1-v3 were REMOVED in v4.
Everything below is true for this repo; keep it true when you change things.

## Layout
- `scripts/jujutsu/` — the game layer:
  - `clans.ts` (pure data: CLANS with roulette weights summing to 100, TECHS, ABILITIES, `rollClan`);
  - `canon.ts` (shikigami data, ORIGIN_TAG, MANUAL);
  - `sorcerer.ts` (per-player world record `sb:jjk:<playerId>`: clan, tech, energy/Vigor, xp, spins, Ten Shadows unlocks, fingers, influence, throat, storage; summon gate; per-second tick);
  - `abilities.ts` (`cast`, toggles, domains, Black Flash, Ratio);
  - `fx.ts` (particle helpers, targeting);
  - `roulette.ts`;
  - `sukuna.ts` (fingers, vessel, possession, drops);
  - `arsenal.ts` (cursed tools, uniforms, forge, on-hit);
  - `ritual.ts` (Ten Shadows exorcism rituals, Rabbit Escape decoys, Mahoraga adaptation);
  - `seal_menu.ts` (Grimório UI).
- Every canon fact is labelled `canon` / `incerto` / `original`. NEVER present invented content as canon (canon.ts, clans.ts, arsenal.ts, the in-game Caderno and documentation/PESQUISA_JJK.md must agree).
- Shikigami infrastructure (legacy from earlier versions, still used): `ai/` (agent, agent_manager, brain, squad orders), `executor/`, `navigation/`, `combat/beasts.ts` (shikigami abilities), `core/species.ts` (species ids are internal and stable: `wolf`=Cão Divino Preto, `owl`=Nue, `bull`=Boi Perfurante, `colossus`=Mahoraga…; APPEND new species to `BEASTS`). Chore task runners (gather/build/mine/craft) and their unit tests remain but no player-facing path reaches them.
- `ui/menu_kit.ts` (`Menu`: header/label/divider + icon buttons), `ui/icons.ts` (all menu icon paths; a test fails if any is missing), `ui/menus.ts` (`show`, `order`, beast member menu), `ui/commands.ts` (`/sombra`, optional text shortcuts).
- `behavior_pack/` — manifest, `shadowbound:beast` entity (GENERATED by `tools/gen_beast_entity.py`), items (GENERATED by `tools/gen_jjk_items.py`), recipe, lang (GENERATED).
- `resource_pack/` — beast client entity, 14 geometries, textures (beasts ≤512 px), animations (per species), attachables for the uniforms (GENERATED), item atlas (GENERATED), menu icons `textures/ui/shadowbound/` (GENERATED), armor layers `textures/models/armor/` (GENERATED).
- `tools/art/generate_art.py` (models, textures, icons, item textures, armor layers), `tools/art/generate_anims.py` (beast animations; `STATES` must match `AnimState`), `tools/gen_beast_entity.py`, `tools/gen_jjk_items.py`, `tools/build.mjs`, `tools/validate-packs.mjs`, `tools/run-tests.mjs`.
- `tests/` — `integration.test.ts` runs the real scripts against `tests/mock/` (a simulator of the API surface we use); `core.test.ts`/`nlu.test.ts` are pure unit tests.
- `dist/` — committed deliverables (`Shadowbound.mcaddon` + `.mcpack`s). `site/template.html` → `site/index.html` (built by build.mjs).
- `optional/` — LLM backend + BDS-only bridge pack; the add-on never depends on them.

## Rules
- Only STABLE Script API: `@minecraft/server` 2.3.0, `@minecraft/server-ui` 2.1.0, min engine 1.26.40 (devDependencies pinned to the same). Never use beta APIs (`chatSend`).
- Owner checks by `player.id` at every entry point; per-player data lives in the world record, never on entities.
- Abilities only hurt hostile mobs (`families: ["monster"]` via `fx.enemiesNear`) and never break blocks.
- Bedrock's font has no emoji outside the BMP: never use them in user-facing strings.
- After editing art/items: `npm run art`. After any change: `npm run all` (typecheck + 44 tests + build). Commit `dist/`.
- User-facing text is Brazilian Portuguese. No sexual content.
